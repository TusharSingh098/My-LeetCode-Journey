### 🌟 Weekly Spotlight: Algorithmic Rigor

* **Complexity:** Time $O(N \log N)$ | Space $O(N)$
* **Architecture:** Overcame the $O(N^2)$ brute-force bottleneck by implementing a modified Merge Sort algorithm integrated with a Binary Indexed Tree to count inversion logic during the conquer phase.
